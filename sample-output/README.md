# Step 3 baseline snapshot

These are the complete generated results from the local Steps 1–3 prototype. Open `conversation_tracker.html` in a browser for the offline viewer, or serve this folder using your cloud environment's browser preview. `step3-preview.jpg` shows the future-aware mode; earlier PNG/JPEG previews preserve the prior stages.

The sentence JSON, NPZ embedding/coordinate arrays, and context audit JSON cover all three real AMI sample meetings. See the project README for record formats and interpretation limits.

AMI transcript-derived data is **CC BY 4.0**, independently of the project's MIT code license. Keep `AMI-LICENCE.txt` and `SOURCE.md` with redistributed sample data. Model weights are not included. The viewer includes Plotly JavaScript with its bundled notices.

This is a saved baseline, not the normal generation directory. Run the pipeline to write new results under `output/`; refresh this snapshot intentionally when recording a new baseline.
